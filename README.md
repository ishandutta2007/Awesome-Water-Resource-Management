# 💧 Awesome-Water-Resource-Management

## 🌊 Top Water Resource Management Platforms Ecosystem
**Curated List of SaaS Products & Open-Source GitHub Projects** 🚀
*Focused on Water Data Management, Utility Operations, Hydraulic Modeling, AMI/SCADA, Leak Detection, Compliance & Hydrologic Monitoring*
**Last updated: August 2026**

This repository tracks notable **SaaS platforms** and **open-source projects** for **Water Resource Management** 🌍. These tools help utilities, agencies, and environmental organizations collect, manage, analyze, and act on water data — covering time-series monitoring, network modeling, customer engagement, compliance, asset performance, and operational optimization.

**Examples** include Aquatic Informatics, Klir, Waterly, Dropcountr, BlueConduit, WaterSmart Software, SwiftComply, Innovyze Info360, Ayyeka, and HydroPoint (the category leaders) 🏆.

**Open-source emphasis**: This section is heavily expanded with every major active project for hydrologic data systems, water network modeling (EPANET ecosystem), open GIS-based water management, SCADA, and research/operational hydrology tools — ideal for utilities, researchers, and public agencies seeking transparent, interoperable water technology.

Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.

## 💻 Open-Source GitHub Projects

- [![GitHub Repo stars](https://img.shields.io/github/stars/OpenWaterAnalytics/epanet?style=social&color=white)](https://github.com/OpenWaterAnalytics/epanet/stargazers) **[EPANET & OpenWaterAnalytics ecosystem](https://github.com/OpenWaterAnalytics)**  
  Foundational open-source toolkit for water distribution system hydraulic and water-quality simulation, plus modern UIs, Python/MATLAB wrappers (WNTR, EPyT), and real-time extensions.

- [![GitHub Repo stars](https://img.shields.io/github/stars/USEPA/SWMM?style=social&color=white)](https://github.com/USEPA/SWMM/stargazers) **[EPA SWMM](https://github.com/USEPA/SWMM)**  
  EPA Storm Water Management Model (SWMM) is a dynamic rainfall-runoff simulation model used for single event or long-term simulation of runoff quantity and quality.

- [![GitHub Repo stars](https://img.shields.io/github/stars/MODFLOW-USGS/modflow6?style=social&color=white)](https://github.com/MODFLOW-USGS/modflow6/stargazers) **[MODFLOW 6](https://github.com/MODFLOW-USGS/modflow6)**  
  MODFLOW is a popular open-source groundwater modeling software developed by the U.S. Geological Survey (USGS).

- [![GitHub Repo stars](https://img.shields.io/github/stars/DOI-USGS/pywatershed?style=social&color=white)](https://github.com/DOI-USGS/pywatershed/stargazers) **[pywatershed (USGS)](https://github.com/DOI-USGS/pywatershed)**  
  Modern Python hydrologic modeling framework motivated by legacy USGS models (PRMS/GSFLOW) for flexible process representation and research.

- [![GitHub Repo stars](https://img.shields.io/github/stars/hydroserver2/hydroserver?style=social&color=white)](https://github.com/hydroserver2/hydroserver/stargazers) **[HydroServer](https://github.com/hydroserver2)**  
  Open-source hydrologic information system for collecting, managing, and sharing time-series observations from environmental and water monitoring sites.

- [![GitHub Repo stars](https://img.shields.io/github/stars/HydrologicEngineeringCenter/WAT?style=social&color=white)](https://github.com/HydrologicEngineeringCenter/WAT/stargazers) **[HEC-WAT (Hydrologic Engineering Center)](https://github.com/HydrologicEngineeringCenter/WAT)**  
  Watershed Analysis Tool that integrates engineering and consequence models for water resources risk and systems analysis.

- [![GitHub Repo stars](https://img.shields.io/github/stars/google-research/flood-forecasting?style=social&color=white)](https://github.com/google-research/flood-forecasting/stargazers) **[OpenHydroNet / flood-forecasting models](https://github.com/google-research/flood-forecasting)**  
  Open implementations of advanced riverine flood forecasting models used in operational systems.

- [![GitHub Repo stars](https://img.shields.io/github/stars/uihilab/HydroLang?style=social&color=white)](https://github.com/uihilab/HydroLang/stargazers) **[HydroLang](https://github.com/uihilab/HydroLang)**  
  Web-based hydrologic programming framework for data retrieval, analysis, modeling, and visualization in the browser.

- [![GitHub Repo stars](https://img.shields.io/github/stars/Giswater/giswater?style=social&color=white)](https://github.com/Giswater/giswater/stargazers) **[Giswater](https://www.giswater.org/)**  
  Open-source platform for integral water cycle management (supply and sewerage) that connects spatial databases, GIS (QGIS), and hydraulic engines such as EPANET and SWMM.

- [![GitHub Repo stars](https://img.shields.io/github/stars/SCADA-LTS/SCADA-LTS?style=social&color=white)](https://github.com/SCADA-LTS/SCADA-LTS/stargazers) **[SCADA-LTS](https://github.com/SCADA-LTS/SCADA-LTS)**  
  Open-source, web-based SCADA system suitable for water distribution, treatment, and industrial monitoring applications.

- [![GitHub Repo stars](https://img.shields.io/github/stars/qanat/qanat?style=social&color=white)](https://github.com/qanat/qanat/stargazers) **[Qanat / Groundwater Accounting Platform](https://github.com/)**  
  Open-source groundwater accounting and water-use tracking tools supporting sustainable management and scenario planning.

- [![GitHub Repo stars](https://img.shields.io/github/stars/aqualink/aqualink?style=social&color=white)](https://github.com/aqualink/aqualink/stargazers) **[AquaLink and remote well/PLC projects](https://github.com/)**  
  Open-source automation and monitoring solutions for wells, pumps, and remote water infrastructure.

### Additional Strong Open-Source Options 🛠️
- QGIS plugins and PostGIS-based water network data models.
- Time-series databases and dashboards (InfluxDB + Grafana, Timescale) tailored to sensor networks.
- Open IoT/MQTT stacks for AMI-style meter and sensor data collection.
- Research codes for non-revenue water, leak detection algorithms, and demand forecasting.

**Frameworks for building custom systems**: Use **Giswater + EPANET/SWMM** for network modeling and GIS integration, **HydroServer** or similar for observation data management, **SCADA-LTS** or open IoT platforms for real-time control and monitoring, and open BI tools for operational dashboards. Combine with local or cloud LLMs for anomaly explanation, report generation, and decision support on top of the open data stack.

- Always ensure any deployed system meets applicable drinking-water, environmental, cybersecurity, and data-governance standards in your jurisdiction.
